MD3｜能力底座

底座不是堆更多组件，而是让能力形成统一上下文

Data 统一上下文，Model 组织Hybrid AI，Tools 把理解变成可执行、可审计的业务动作。

Data

统一业务上下文
  • 订单、客户、维修、库存、物流与知识共享同一业务定义。
  • 让同一 Customer Promise 能被多个 Agent 访问、更新和追溯。
  • 接入数据血缘、权限与治理，不只是增加数据源。

Model

Hybrid AI 服务协同
  • 大模型理解与解释；小模型分类、路由与高频判断。
  • 时序模型预测；优化模型在约束下权衡决策。
  • 规则与Ontology限定边界，避免“一模型包打天下”。

Tools

执行与审计
  • Connector 连接系统；Tools 封装API、MCP、查询和Action。
  • 低风险、重复性动作可自动执行。
  • 高风险动作保留权限、人工确认、日志与回放。

面向人：ISS Dashboard 呈现上线情况、采用率、流程改善与业务收益。

面向Agent：Marketplace 登记并发现 Agent、Skill、Tools、Models、Ontology，支持复用与治理。
