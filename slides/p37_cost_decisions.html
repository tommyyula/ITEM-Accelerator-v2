6.11 模型路由与成本治理，先列决策再谈价格

成本治理不是先定价，而是先把任务、模型、数据边界、质量证据与计量方式对齐；任何费率与分摊方式均待确认。

任务到能力的路由候选

业务任务候选能力路由判断与证据
稳定分类、意图与高频路由 小模型规则 优先低成本与可重复性；需验证目标、阈值、人工接管。
领域理解、解释与多 Agent 协作 ISS-LRM通用 LLM 按能力边界、数据使用范围、上下文与质量指标选择；部署位置待确认。
ETA、需求、风险等预测 预测模型 输出时间窗、风险或置信信息；必须关联事实源、版本和业务 Owner。
库存、运输、料件与计划权衡 优化模型 在约束条件下求解方案；人工审批边界与执行 Action 待确认。

先填四个治理字段

能力边界

ISS-LRM、通用 LLM、预测、优化、小模型各自能做什么？待确认。

数据与部署

部署位置、数据使用范围、隔离与日志留存要求。待确认。

计量口径

调用次数、Token、GPU 时间、实例或业务能力包，候选并列。

成本回流

业务线、区域、模型等级或 Skill 的分摊维度；回流 ISS Dashboard。

质量与采用必须一起看

建议把 Adoption、响应、错误、人工介入、单位业务价值与调用成本放在同一反馈环；不写增长数字，不承诺定价。

可在 Dashboard 观察模型路由变化，但字段、刷新频率与 Owner 仍需确认。

会后决策项

Skill-based JEV Harness 的正式名称、JEV含义与第一阶段边界；ISS Skill-based Model 的目标架构、Skill Owner、目录和治理规则；Hollis Phase I / II 的时间、交付物与决策门。

“编辑部”含义与是否进入 Demo 未确认，不纳入正式案例。
