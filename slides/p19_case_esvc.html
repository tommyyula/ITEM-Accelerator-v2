2.6 eSVC Small Model：高频判断与成本分层

把简单、高频、可验证的判断交给轻量模型或规则，让复杂任务再进入 LLM；本例是补充能力，不抢 BO 主线。

▷
Demo 视频 · 待接入 16:9 视频区 · 待接入素材

路由路径

eSVC 入口 → 小模型/规则分类 → 知识、Agent 或人工队列；复杂判断再调用 LLM。情绪、意图、路由中的准确目标尚待确认。

观看检查点

1. 入口输入与分类标签是否明确？
2. 小模型为什么能承担该判断？
3. 不确定或低置信度如何升级？
4. 路由结果是否记录，便于复核 Token 与质量？

待确认目标

情绪识别、意图识别、路由或其他能力；不替业务 Owner 猜定。

轻量层

规则、模板与小模型处理稳定高频任务，减少不必要的上下文。

复杂层

需要解释、跨系统协作或长上下文时再调用 LLM/Agent。

验收证据

分类质量、升级率、Token 使用口径、人工修正回流；无生产效果承诺。

与 BO 的关系

eSVC Small Model 可作为入口分层与 Model Hub 的示例；它帮助 BO 等复杂流程先过滤请求，但不替代跨组织事实、预测、优化与审批闭环。
