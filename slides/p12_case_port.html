业务任务链

任务 → 打单 → 监控 → 派车 → 状态更新 → 收付款；Master Agent 拆分子 Agent，状态事件触发后续动作。

观看检查点

1. 输入运输任务后，是否生成可追踪的子任务？
2. 状态变化如何触发监控、派车与同步？
3. 异常是否明确交人、保留上下文与日志？
4. 结果能否回放，而不是只显示最终答案？

流程证明

订单、监控、派车、状态、结算由标准 Tools 与 Connector 串联。

迁移讨论

可迁移至服务供应链、Field Service、Global Logistics；迁移条件待确认。

指标口径

介入次数、异常处置时间、状态同步完整性、过程可追踪性；无现成数据。
