4. 两套 Business Oriented Tools，共用同一底座

Runtime 面向业务使用与配置，Factory 面向专业共建与治理；分工不同，但共享业务语义、能力目录和上线边界。

01

表达业务目标

Citizen Business User 用业务语言提出目标，不必先理解 Prompt、MCP 或模型细节。

02

生成可用草案

ITEMGPT Runtime 将目标映射到标准模板、字段、术语、输出与权限。

03

专业共建与验收

Agent Factory 连接 Ontology、Data、Model、Skill、MCP 与 Tools，完成沙盒评估。

04

发布后持续治理

版本、日志、人工介入与成本质量回流；是否具备现成能力，需逐项确认。

两类角色，不是两个平台

入口主要责任
ITEMGPT Runtime一线和 Citizen User 使用、配置、反馈；高风险 Action 仍按权限确认。
Agent FactoryDT、FDE、Senior User、Developer 构建、Qualification、发布与治理。

共享的可复用资产

  • Ontology 与业务术语：让目标、字段、状态和规则一致。
  • Data / Model Hub：接入事实、知识、预测、优化和分层模型。
  • Connector / Tools / Action：可调用、可审计，权限边界先于自动化。
  • 治理规范：沙盒、测试集、版本、日志与人工接管。
